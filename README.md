# 电商用户行为数据分析

基于 5630 名用户 × 19 字段的电商用户快照数据，使用 Python（pandas / numpy / matplotlib）完成：

- **RFM 八类用户分层**：R/F/M 三维打分，圈定 8 类运营人群
- **改编版价值漏斗**：全体 → 上月有单 → 复购 → 高价值（5630 → 5372 → 3621 → 734）
- **流失交叉分析**：定位消费水平（M）为流失最强分层信号（低 M 流失率最高 29% vs 大盘 17%）
